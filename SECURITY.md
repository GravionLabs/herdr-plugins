# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately
through GitHub private vulnerability reporting:

1. Open the [Security tab](https://github.com/GravionLabs/herdr-plugins/security) of this repository.
2. Choose **Report a vulnerability** and describe the problem, the affected plugin and the steps to reproduce it.

We acknowledge a report as soon as we can, keep you informed while we work on
a fix, and credit you in the advisory unless you prefer otherwise.

## Supported versions

Only the latest release receives security fixes.
