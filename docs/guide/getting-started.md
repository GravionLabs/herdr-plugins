# Getting started

Install a plugin from git with herdr:

```sh
herdr plugin install GravionLabs/herdr-plugins/<plugin>
```

Trigger an action without a keybinding:

```sh
herdr plugin action invoke <plugin>.<action>
```

See [Plugins](../plugins/index.md) for the list of plugins and [Public names](../naming.md) for their actions and config keys.
