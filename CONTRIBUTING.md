# Contributing

Thank you for your interest in herdr-plugins.

- The contributor guide is tracked in [#107](https://github.com/GravionLabs/herdr-plugins/issues/107) and will move into the documentation site (see [#72](https://github.com/GravionLabs/herdr-plugins/issues/72)) once it is published.
- Please follow the [Code of Conduct](CODE_OF_CONDUCT.md).
- Report security problems privately, as described in [SECURITY.md](SECURITY.md).
- Use [Conventional Commits](https://www.conventionalcommits.org/) and open pull requests against `release/next`.
- Run `npm ci`, `npm run typecheck` and `npm test` before you push; every change ships with tests.
